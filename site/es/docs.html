La guía completa de Guaraci

De la instalación al detalle de cada campo: todo lo que necesita para recolectar datos públicos oficiales, con la interfaz web o con la línea de comandos. Sin prisa, sin jerga escondida, con cada uno de los 259 conjuntos de datos documentado uno a uno.

Visión general

Guaraci es un orquestador de descargas de datos públicos: se conecta directamente a las fuentes oficiales (DATASUS mediante el FTP de microdatos, catálogo abierto del Ministerio de Salud, IBGE por la API SIDRA, NASA y gov.br, entre otras) y entrega los datos listos para usar en CSV, Parquet o SQLite.

Tres principios guían el proyecto:

  • Fuente primaria, siempre. Guaraci nunca busca en espejos ni en curadurías de terceros: cada base viene del sistema oficial que la produce. Usted recibe el dato con la actualización que la fuente haya publicado, trazable hasta el origen.
  • Fidelidad al dato original. La recolección preserva el contenido publicado, y la conversión de formatos técnicos (como el .dbc del DATASUS) no altera los valores.
  • Docker primero. El camino oficialmente soportado corre en un contenedor Docker, de modo que el entorno es idéntico en cualquier equipo, sin conflictos de dependencias.

Hay dos puertas de entrada, con el mismo motor: la interfaz web (formularios en el navegador, sin código) y la línea de comandos guaraci fetch (para automatización y scripts). Ambas leen el mismo schema de parámetros documentado en el catálogo.

1 · Instalación

Necesita dos programas gratuitos: Git (copia el proyecto) y Docker Desktop (ejecuta Guaraci). Instale ambos con las opciones predeterminadas y deje Docker Desktop abierto.

1.1 Copie el proyecto

Abra la terminal (en Windows, busque PowerShell en el menú Inicio) y escriba:

PowerShell
> git clone https://github.com/autoaihub/guaraci.git
> cd guaraci

1.2 Verifique Docker antes de continuar

La causa más común de fallo en la instalación es que Docker Desktop no esté listo (cerrado, todavía abriéndose o con el motor sin responder), y no un problema de Guaraci. Ejecute primero el diagnóstico de abajo siempre que algo se trabe:

PowerShell: guaraci
> .\scripts\desktop\check-docker.cmd
[OK] Docker CLI
[OK] Docker Desktop (engine)
✔ Docker está listo.

En Linux o macOS: ./scripts/desktop/check-docker.sh. El script dice exactamente qué falla y cómo corregirlo. Si pasa ([OK] en todo) y Guaraci igualmente da error, el problema es de Guaraci, no de Docker.

1.3 Construya la imagen (una sola vez)

PowerShell: guaraci
> docker build -t guaraci .
[+] Building... ok
Rehaga el build solo cuando haya actualización de dependencias. Si sospecha de una caché dañada, use docker build --no-cache -t guaraci ..

1.4 Encienda Guaraci

Forma recomendada (Windows). El launcher levanta el contenedor, espera el health check y abre la interfaz solo:

PowerShell: guaraci
> .\scripts\desktop\start-guaraci.cmd
✔ Guaraci en marcha: http://localhost:8002/

En Linux o macOS: ./scripts/desktop/start-guaraci.sh. Para ver el estado, status-guaraci; para apagar, stop-guaraci.

Forma manual (útil para depurar: la terminal sigue mostrando los logs y Ctrl+C la detiene):

PowerShell: guaraci
> docker run --rm -it -p 8002:8000 -v "${PWD}:/app" guaraci uvicorn guaraci.api.main:app --host 0.0.0.0 --port 8000 --no-access-log
Monte siempre el volumen (-v "${PWD}:/app"). Sin él, las descargas y los manifiestos se pierden cuando el contenedor termina.

1.5 Compruebe que todo funciona

PowerShell
> Invoke-RestMethod http://localhost:8002/health
{"status": "ok", "version": "0.6.0"}

1.6 Problemas comunes

SíntomaSolución

Ejecute .\scripts\desktop\check-docker.cmd (o .sh), que señala el elemento exacto que falló. Normalmente basta con abrir Docker Desktop y esperar a que el ícono de la ballena deje de decir “Starting...”; si se traba, reinicie con wsl --shutdown y ábralo de nuevo.

2 · Interfaz web

Con Guaraci en marcha, la interfaz queda en http://localhost:8002. Todo el flujo ocurre en una pantalla:

  1. Elija la fuente. La lista trae las 271 entradas del catálogo (259 conjuntos de datos distintos, más los caminos alternativos hacia el mismo conjunto) con búsqueda. Cada una expone sus propios parámetros, y el formulario se arma solo a partir del schema (el mismo documentado en el catálogo).
  2. Complete los filtros básicos. Período (años), estados, grupos o enfermedades, según la fuente. Los campos avanzados (paginación, URL alternativa, snapshot en bruto) quedan plegados, y los valores predeterminados sirven para la mayoría de los casos.
  3. Elija el formato de exportación. CSV (se abre en Excel), Parquet (análisis de datos) o SQLite (base local). Sin formato, Guaraci solo recolecta y registra el manifiesto.
  4. Cree la descarga y sígala. La barra de progreso y el log en vivo muestran cada archivo mientras se busca, valida y convierte. Los jobs quedan en el historial, y se pueden repetir o depurar después.
  5. Abra el resultado. Los archivos quedan en la carpeta Guaraci Downloads (en el Escritorio, por defecto), junto con un manifest.json que describe la recolección.
Para fuentes voluminosas del DATASUS (SIA, SIH, CNES), use el preflight de descubrimiento antes de descargar: cuenta los archivos por grupo y UF sin transferir nada, en la interfaz o con guaraci fetch discover.

3 · Línea de comandos

El grupo guaraci fetch alcanza cualquier fuente registrada con cuatro subcomandos. Dentro de Docker, anteponga docker run --rm -v "${PWD}:/app" guaraci (o use el shell interactivo).

3.1 fetch list: qué existe

terminal
> guaraci fetch list
sih · sim · sinan · sinasc · dengue · nasa_power · ibge_populacao ... 271

3.2 fetch schema: los parámetros de una fuente

terminal
> guaraci fetch schema dengue
nu_ano (string) · output_format [csv|parquet|sqlite] · batch_size (int, 1000) ...

3.3 fetch discover: mida antes de descargar

Disponible para el SIH y los once sistemas de microdatos por FTP del DATASUS (SIA, CNES, SINASC, etc.): cuenta archivos por grupo y UF sin descargar nada. Con --sizes, suma también el tamaño total. SIM y SINAN resuelven sus archivos internamente durante la recolección y quedan fuera del preflight.

terminal
> guaraci fetch discover sih --set start_year=2024 --set end_year=2024 --set states=SP --sizes
RD · SP · 12 files · 198.4 MB

3.4 fetch run: recolecte

terminal
> guaraci fetch run sinan --set disease=DENG --set start_year=2023 --set end_year=2024 --format csv
DENGBR23.dbc → csv → sinan_deng_2023-2024.csv

Reglas útiles:

  • --set CLAVE=VALOR se convierte automáticamente al tipo declarado en el schema (entero, booleano, lista).
  • Omita --format para recolectar sin exportar (solo se graba el manifiesto).
  • -o CARPETA cambia el destino (por defecto: Guaraci Downloads en el Escritorio).
  • Las credenciales de la NASA nunca son opciones de línea, solo variables de entorno (sección 5).

Cada fuente del catálogo trae un ejemplo de fetch run listo para copiar.

4 · Formatos y salida

FormatoCuándo usarlo
csvAbrir en Excel o LibreOffice y compartir con quien no programa.
parquetAnálisis de datos (pandas, polars, R, Spark): compacto y rápido, preserva los tipos.
sqliteConsultas SQL locales sin servidor, en un único archivo .db.
  • manifest.json: toda recolección graba un manifiesto con fuente, parámetros, archivos y horarios, que es el registro de procedencia del dato.
  • keep_raw=true: además de la exportación, guarda el snapshot en bruto (raw/*.jsonl en las APIs) para auditoría.
  • export_warning: si los filtros dejan los registros en cero o la paginación se trunca (max_pages), el aviso aparece en el manifiesto y en los logs. Es el primer lugar donde mirar cuando “no llegó nada”.
  • Formatos de origen: los archivos .dbc y .DBF del DATASUS se decodifican automáticamente, y usted nunca tiene que lidiar con ellos.

5 · Credenciales (NASA)

Casi todo en Guaraci prescinde de registro. Las excepciones son dos fuentes de la NASA, y las claves son gratuitas:

nasa_firmsMAP_KEYGUARACI_FIRMS_MAP_KEYfirms.modaps.eosdis.nasa.gov
nasa_gpmEarthdataGUARACI_EARTHDATA_TOKENurs.earthdata.nasa.gov (autorice la app NASA GESDISC DATA ARCHIVE)

nasa_power y todas las fuentes de IBGE, OpenDataSUS, DATASUS y gov.br no exigen credencial. Por seguridad, las claves se leen solo del entorno: nunca entran como parámetro de un job ni se graban en un manifiesto.

PowerShell
> $env:GUARACI_FIRMS_MAP_KEY = "su-clave-aqui"
(Linux/macOS: export GUARACI_FIRMS_MAP_KEY=su-clave-aqui)

6 · Orquestador (uso en servidor)

Para quien mantiene un acervo continuo (como el data lake Sabiá), guaraci orchestrate automatiza la recolección en dos capas bronze:

  • raw/: el archivo oficial en bruto, con la granularidad nativa de la fuente (el SINAN anual sigue anual; el SIH mensual sigue mensual).
  • refined/: las mismas filas repartidas en el árbol uniforme fuente/grupo/UF/año/mes, divididas por la fecha del evento.

Comandos: orchestrate profiles (cadencia de cada fuente), plan (dry run), backfill (historial completo), update (solo el delta, guiado por un ledger CSV) y status. Los wrappers scripts/server/orchestrate.{sh,ps1}, listos para cron, se ocupan del lock y del log. Los detalles están en docs/ORCHESTRATOR.md en el repositorio.

7 · Buenas prácticas

  • Empiece pequeño. Use la ventana de tiempo más corta y los filtros más estrechos posibles, y amplíe cuando el flujo esté validado.
  • Mida antes de descargar. En las fuentes FTP voluminosas (SIA, SIH, CNES), ejecute primero fetch discover, porque las selecciones amplias pueden resolverse en miles de archivos y muchos gigabytes.
  • Exporte solo cuando lo necesite. Defina output_format solo cuando quiera el dataset final; la recolección sin exportación es más rápida y ya queda registrada.
  • Vigile el export_warning. Denuncia exportaciones vacías y paginación truncada.
  • El dato del año en curso es parcial. Las fuentes del DATASUS aceptan el año en curso, pero hay un retraso de publicación de unos 2 a 3 meses, así que compare con cuidado.
  • Cite la fuente oficial. Las condiciones de uso son las de la institución productora; Guaraci trae un CITATION.cff por si también desea citar la herramienta.
