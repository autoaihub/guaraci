What Guaraci is

From scattered data to useful information

Brazil's public data exists, but it is spread across dozens of portals, each with its own format and its own way of downloading. Guaraci fetches everything straight from the official source and delivers it in one place, with quality, integrity and fidelity to the original data.

Without Guaraci

Finding data is hard work

  • Each dataset sits on a different government portal.
  • Technical formats that are hard to open (such as .dbc files).
  • You have to repeat the download state by state, year by year.
  • It is easy to end up with outdated data or data from intermediaries.
With Guaraci

Everything on a single path

  • No more hunting across dozens of different portals.
  • Delivered ready to use: CSV, Parquet or a database.
  • You choose the period, state and slice, and it downloads everything.
  • Always from the official source, with no intermediaries.

How to use

From zero to data in 5 steps

You do not need to know how to code: once installed, everything happens in a web interface in your browser. The terminal only appears during installation, and we show exactly what to type.

1

Install the two required programs

Guaraci runs inside Docker (a “container” that already comes fully configured) and is copied to your computer with Git. Both are free:

Download Docker Desktop Download Git
Install with the default options (“Next, Next, Finish”). After installing, open Docker Desktop and leave it open, because it must be running for the next steps.
2

Copy Guaraci to your computer

Open the terminal (on Windows, look for PowerShell in the Start menu) and type the two lines below, pressing Enter after each one:

PowerShell
> git clone https://github.com/autoaihub/guaraci.git
Cloning into 'guaraci'... done.
> cd guaraci

Before moving on, confirm that Docker is ready. That way, if something gets stuck later, you already know whether the cause is Docker or Guaraci:

PowerShell: guaraci
> .\scripts\desktop\check-docker.cmd
[OK] Docker CLI
[OK] Docker Desktop (engine)
✔ Docker is ready. You can go on with “docker build -t guaraci .”
Got [FAIL] on any line? The script shows exactly what to do (open Docker Desktop, restart, and so on). Fix it before going to the next step, and see also the common problems.
3

Build Guaraci (first time only)

This command prepares everything Guaraci needs inside Docker. It takes a few minutes, but you only need to do it once:

PowerShell: guaraci
> docker build -t guaraci .
[+] Building...
✔ Image “guaraci” created successfully
4

Start Guaraci

A single command starts the server and opens the interface in your browser by itself, at http://localhost:8002:

PowerShell: guaraci
> .\scripts\desktop\start-guaraci.cmd
health check...
✔ Guaraci is up: http://localhost:8002/
On Linux or macOS, the equivalent command is ./scripts/desktop/start-guaraci.sh. To shut it down later: stop-guaraci.
5

Request your data in the interface

On the screen that opens, choose the source (for example, dengue), fill in the filters (years, state, format) and click create the download. You follow the progress live and, at the end, the files are in the Guaraci Downloads folder on your Desktop.

localhost:8002

Something went wrong? The installation documentation has the fix for the most common problems (busy port, Docker stopped, and so on), and you can write to vogel@usp.br.
