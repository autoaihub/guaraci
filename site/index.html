O que é o Guaraci

Do dado espalhado à informação útil

Os dados públicos do Brasil existem — mas ficam espalhados em dezenas de portais, cada um com seu formato e jeito de baixar. O Guaraci busca tudo direto da fonte oficial e entrega em um só lugar, com qualidade, integridade e fidelidade ao dado original.

Sem o Guaraci

Procurar dados dá trabalho

  • Cada base fica em um portal diferente do governo.
  • Formatos técnicos e difíceis de abrir (como arquivos .dbc).
  • É preciso repetir o download estado por estado, ano por ano.
  • É fácil pegar dado desatualizado ou vindo de intermediários.
Com o Guaraci

Tudo em um caminho só

  • Chega de caçar em dezenas de portais diferentes.
  • Entregue pronto para usar: CSV, Parquet ou banco de dados.
  • Você escolhe período, estado e recorte — ele baixa tudo.
  • Sempre da fonte oficial, sem intermediários.

Como usar

Do zero aos dados em 5 passos

Você não precisa saber programar: depois de instalar, tudo acontece em uma interface web no seu navegador. O terminal só aparece na instalação — e mostramos exatamente o que digitar.

1

Instale os dois programas necessários

O Guaraci roda dentro do Docker (um "contêiner" que já traz tudo configurado) e é copiado para o computador com o Git. Os dois são gratuitos:

Baixar Docker Desktop Baixar Git
Instale com as opções padrão ("Avançar, Avançar, Concluir"). Depois de instalar, abra o Docker Desktop e deixe-o aberto — ele precisa estar ativo para os próximos passos.
2

Copie o Guaraci para o seu computador

Abra o terminal — no Windows, procure por PowerShell no menu Iniciar — e digite as duas linhas abaixo, apertando Enter após cada uma:

PowerShell
> git clone https://github.com/autoaihub/guaraci.git
Cloning into 'guaraci'... done.
> cd guaraci

Antes de seguir, confirme que o Docker está pronto — assim, se algo travar mais adiante, você já sabe se a causa é o Docker ou o Guaraci:

PowerShell — guaraci
> .\scripts\desktop\check-docker.cmd
[OK] Docker CLI instalado
[OK] Docker Desktop rodando (engine responde)
✔ Docker está pronto. Pode seguir com "docker build -t guaraci ."
Deu [FALHA] em alguma linha? O script mostra exatamente o que fazer (abrir o Docker Desktop, reiniciar etc.). Resolva antes de ir para o próximo passo — veja também problemas comuns.
3

Monte o Guaraci (só na primeira vez)

Este comando prepara tudo o que o Guaraci precisa dentro do Docker. Demora alguns minutos, mas só precisa ser feito uma vez:

PowerShell — guaraci
> docker build -t guaraci .
[+] Building… instalando dependências ⏳
✔ Imagem "guaraci" criada com sucesso
4

Ligue o Guaraci

Um único comando sobe o servidor e abre a interface sozinho no navegador, em http://localhost:8002:

PowerShell — guaraci
> .\scripts\desktop\start-guaraci.cmd
Aguardando health check…
✔ Guaraci no ar — abrindo http://localhost:8002/
No Linux ou macOS, o comando equivalente é ./scripts/desktop/start-guaraci.sh. Para desligar depois: stop-guaraci.
5

Peça seus dados pela interface

Na tela que abrir: escolha a fonte (ex.: dengue), preencha os filtros (anos, estado, formato) e clique em criar o download. Você acompanha o progresso ao vivo e, no final, os arquivos ficam na pasta Guaraci Downloads, na sua Área de Trabalho.

localhost:8002 — Guaraci
dengue — casos notificados (Ministério da Saúde)
2023 → 2024
SP
CSV (abre no Excel)
baixando página 42/58 · 96,4 MB transferidos · ETA 00:41
✔ exportado: dengue_2023-2024_SP.csv → Guaraci Downloads
Algo deu errado? A documentação de instalação tem a solução para os problemas mais comuns (porta ocupada, Docker parado etc.) — e você pode escrever para vogel@usp.br.
