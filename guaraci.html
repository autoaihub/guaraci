O que é o Guaraci

Do dado espalhado à informação útil

Os dados públicos do Brasil existem — mas ficam espalhados em dezenas de portais, cada um com seu formato, senha e jeito de baixar. O Guaraci é o orquestrador de downloads que busca tudo isso direto da fonte oficial e entrega em um só lugar, com qualidade, integridade e fidelidade ao dado original.

Sem o Guaraci

Procurar dados dá trabalho

  • Cada base fica em um portal diferente do governo.
  • Formatos técnicos e difíceis de abrir (como arquivos .dbc).
  • É preciso repetir o download estado por estado, ano por ano.
  • É fácil pegar dado desatualizado ou vindo de intermediários.
Com o Guaraci

Tudo em um caminho só

  • Chega de caçar em dezenas de portais diferentes.
  • Já entregue pronto para usar (CSV, Parquet ou banco de dados).
  • Você escolhe período, estado e recorte — ele baixa tudo.
  • Sempre da fonte oficial, sem intermediários.

Perguntas frequentes

Dúvidas antes de começar

As perguntas que mais aparecem de quem está conhecendo o projeto.

Sim, é gratuito e de código aberto, sob licença MIT. Não há cadastro nem senha para usar o Guaraci: você baixa o projeto do GitHub e roda na sua própria máquina. Algumas fontes externas podem exigir uma chave de acesso própria delas — a documentação indica quais.

Baixa da fonte. O Guaraci não guarda uma cópia própria dos dados nem serve como intermediário: quando você pede um conjunto, ele vai buscar no sistema oficial que o produz (DATASUS, catálogo aberto do Ministério da Saúde, IBGE, NASA ou os sistemas de saneamento do gov.br). O que você recebe é o dado oficial, com a atualização que a fonte tiver publicado.

Um pouco. O uso principal é por linha de comando, então é preciso estar confortável em abrir um terminal e rodar comandos. Você não precisa escrever código nem conhecer as particularidades de cada fonte — o Guaraci cuida disso. Se você já usa R, Python ou Stata para analisar dados, o nível exigido está bem dentro do seu alcance.

Em CSV, Parquet ou banco SQLite, prontos para abrir em qualquer ferramenta de análise. Isso vale inclusive para as bases do DATASUS distribuídas em .dbc, um formato compactado antigo que costuma travar quem está começando: o Guaraci faz a conversão para você.

Git e Docker. É o caminho oficialmente suportado hoje para rodar o Guaraci na sua máquina.

É o data lake — um grande acervo de dados sempre atualizado — abastecido pelo Guaraci. No futuro, o Sabiá vai disponibilizar uma interface própria de consulta, sem que você precise instalar o Guaraci (repositório, Docker etc.). Por enquanto, essa interface ainda está em construção.

Sim. São dados públicos, obtidos das fontes oficiais — as condições de uso são as da instituição que produz cada base, e recomendamos citá-la sempre. O Guaraci em si é MIT e traz um arquivo CITATION.cff no repositório, caso você queira também referenciar a ferramenta usada na coleta.

Dá. O catálogo cresce conforme a necessidade de quem usa: escreva para vogel@usp.br contando qual base você precisa e o órgão que a publica. O mesmo vale para relatar um erro em alguma coleta — quanto mais específico o relato, mais rápido o ajuste.
