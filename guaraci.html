O que é o Guaraci

Do dado espalhado à informação útil

Os dados públicos do Brasil existem — mas ficam espalhados em dezenas de portais, cada um com seu formato, senha e jeito de baixar. O Guaraci é a ponte que traz tudo isso para um só lugar, direto da fonte oficial.

Sem o Guaraci

Procurar dados dá trabalho

  • Cada base fica em um portal diferente do governo.
  • Formatos técnicos e difíceis de abrir (como arquivos .dbc).
  • É preciso repetir o download estado por estado, ano por ano.
  • Fácil pegar dado desatualizado ou de intermediários.
Com o Guaraci

Tudo em um caminho só

  • Um único ponto de acesso para 90+ conjuntos de dados.
  • Já entregue pronto para usar (CSV, Parquet ou banco de dados).
  • Você escolhe período, estado e recorte — ele baixa tudo.
  • Sempre da fonte oficial, sem intermediários.

Como usar

Três passos para chegar aos dados

O caminho é sempre o mesmo, não importa a base que você escolher.

1

Escolha o tema

Selecione a base ou o assunto que deseja consultar — saúde, população, saneamento ou clima.

2

Defina o recorte

Informe período, estado, município e outros filtros para chegar exatamente ao conjunto que precisa.

3

Receba os arquivos

Acompanhe o download e receba os dados prontos para usar, reunidos em uma pasta sua.

Três formas de usar, para cada tipo de pessoa

Do usuário que só quer baixar um arquivo até o sistema que precisa integrar tudo automaticamente.

Aplicativo no computador

Uma tela simples para escolher a base, preencher os filtros e acompanhar o download — sem precisar saber programar.

Para quem quer praticidade

Linha de comando

Um comando único e direto para baixar qualquer base, ideal para quem automatiza tarefas ou repete coletas com frequência.
